# toques-trombeta-jogo

Aplicação mobile para treinamento e avaliação de identificação de toques de corneta.

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` no navegador.

## Créditos e origem dos áudios

Os toques utilizados no projeto mantêm como fonte institucional de referência a página
[Toques de Corneta — Escola Estadual da Polícia Militar Tiradentes de Cuiabá](https://escolatiradentescuiaba.com/toque-de-corneta/).

afiliação oficial com a Escola Estadual da Polícia Militar Tiradentes, com a Polícia
